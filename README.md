## ☁️ Vercel-এ ক্লাউড ডাটাবেস (MongoDB Atlas) সেটআপের সহজ নিয়ম

1. [mongodb.com/cloud/atlas](https://www.mongodb.com/cloud/atlas)-এ একটি ফ্রি অ্যাকাউন্ট করে ১ মিনিটে একটি ফ্রি ক্লাস্টার তৈরি করুন।
2. **Connect**-এ ক্লিক করে Connection String কপি করুন (যেমন: `mongodb+srv://user:pass@cluster0.xxx.mongodb.net/bdab?retryWrites=true&w=majority`)।
3. আপনার [Vercel Dashboard](https://vercel.com)-এ প্রজেক্টের **Settings > Environment Variables** এ যান।
4. নতুন ভেরিয়েবল যোগ করুন:
   - **Key:** `MONGODB_URI`
   - **Value:** `আপনার_কপি_করা_মঙ্গোডিবি_ইউআরএল`
5. ব্যাস! এখন যে কেউ সদস্যের ছবি আপলোড করুক, রক্তদাতা যুক্ত করুক বা রক্তের আবেদন করুক — সবকিছু সরাসরি আপনার ক্লাউড ডাটাবেসে সুরক্ষিত থাকবে।
